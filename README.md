# Geo Data Insights

Geospatial data analytics dashboard.

## Features

- Dashboard
- Authentication pages
- Features, pricing and FAQ

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/geo-data-insights-hub.git
cd geo-data-insights-hub
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
